# Music House Rev 4 — owner findings after first physical read (21 Nov 2026)
Cog analysis; geometry numbers are calculations, not physical results. Aperture coordinates and window sizes are NOT being changed. All proposals are leaf-artwork/instruction changes for Keeper/Scribe to decide.

## A. Neighbouring letters are visible in each window (owner-observed; confirmed in my 300 dpi render)
Ø10.5 mm window = radius 5.25 mm. Rev 4 type is small and tightly set, so 3-4 letters and parts of a second line show per window; "centred letter" is not self-evident.
Isolation rule (calculation): a neighbouring glyph is hidden only if its nearest ink edge is >= 5.25 mm from the window centre.
 - Horizontal: letter pitch p >= 5.25 + glyph_width/2. For ~4 mm-wide glyphs (about 8 mm type, ~5.6 mm cap height) p >= ~7.5-8 mm, i.e. wide letter-spacing on the four read lines.
 - Vertical: line interval >= 5.25 + cap_height/2 = ~8 mm.
 - Effect: exactly one glyph per window; also makes the reading tolerant of small placement/rotation error (window centres lie 10.5-15.0 mm from the cross; ~2.7 mm slack = roughly +/-10 deg of rotation, calculated).
 - Cost: ~8 mm pitch needs far more width than an 82 mm leaf. A full sheet has the room.
 - Other (artwork) options for Scribe: make the four read letters visually distinct (heavier/larger) without a new cipher. Cog can check any proposed layout by rendering it and counting glyphs visible per window and under +/-5 mm shift, +/-10 deg rotation.

It is not an optical requirement: the optics only need the cross position and the rotation reference. If the dossier is now a folder with full sheets, the leaf can be any size.
